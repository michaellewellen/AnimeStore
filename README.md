# AnimeStore

With the extensive aid of AI we have added a postres database and implemented tables for logging.  The nav bar successfully offers login and log out options as well as registering new people to the log in screen 

Per our discussion in class we are building an e-commerce store we will want to develop customer facing pages which include

All Transactions (Guest or Logged in)
* Landing/Welcome page.  Ideally this will welcome and show the results of a branded search for 'promoted' items
* Search / Filter Page for the customer to search our product database for products they might want. Ideally this will display some information about the product. 
* Detail Page will take a selected item and display everything we have about that particular product. 
* Basket / Order page to view items added to the basket
* Delivery Page to establish shipping options and verify address for delivery
* Secure payment page to take the customers credit card.
* Confirmation page to summarize the order and provide tracking information

Logged in Customers will have
* suggested purchase page
* order history page


Back End / Customer Service Pages
* Customer page - Offer the ability to look up a customer by name / email address and review demographic information and order history. 
* Return merchandise page. Old School having a customer service rep initiate this (OPTIONAL CUSTOMER DRIVEN)

Back End / Administration
* Inventory 
* Warehouse Ordering pages
* Wholesaler contact list
* Report generator to query against any of the database tables with a free form SQL option
